# 🎟️ Ticket Booking Application

A full-stack **Ticket Booking Application** built using modern web technologies. The application allows users to explore events and book tickets through a simple and responsive interface.

## 🌐 Live Demo

🔗 https://ticket-frontend5-vlmg.vercel.app/

## 📌 Project Overview

The Ticket Booking Application is designed to provide an easy and convenient way for users to view available events and book tickets online.

The project includes a React frontend connected with a Node.js/Express backend and MongoDB database.

## ✨ Features

- 🔐 User Authentication
- 🎟️ Online Ticket Booking
- 🎫 Ticket Management
- 📅 Event Management
- 👤 User-based booking information
- 🔎 Event browsing
- 📱 Responsive user interface
- ⚡ REST API integration
- 🗄️ MongoDB database integration
- 🔒 JWT-based authentication
- 🚀 Deployed frontend
